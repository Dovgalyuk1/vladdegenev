# VLAD DEGENEV — $VLAD

Одностраничный сайт мем-персонажа Vlad Degenev. Он не торгует — он стоит под чейном
с открытым капюшоном и собирает всё, что с него падает.

## Структура

```
vlad/
├── index.html      — весь сайт (стили и скрипты инлайн, без сборки)
├── assets/
│   ├── cut-full.webp   — персонаж в полный рост (вырезан с зелёного фона)
│   ├── cut-head.webp   — голова (футер, карточка победы)
│   ├── ava.webp        — og-картинка
│   └── favicon.png
└── README.md
```

## Настройка под листинг

В начале `<script>` в `index.html`:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку — пока пусто, кнопка BUY неактивна
```

## Что внутри

- Герой: персонаж стоит под падающими деньгами (canvas), клик по нему сыплет монеты + звук.
- Мини-игра **THE DROP**: водишь его мышкой/стрелками, ловишь кэш и токены, уворачиваешься
  от красных — 8 мешков, каждый открывает карточку в секции «WHAT HE CAUGHT».
- Музыка (маримба-петля на Web Audio, без файлов) и звуки — кнопки SOUND / MUSIC в шапке.
- Проверено: 1440×1000, 1352×631, 390×844 — без горизонтального скролла и ошибок в консоли.
